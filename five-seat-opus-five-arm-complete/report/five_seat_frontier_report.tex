\section{Narrative summary}
\textbf{The setup / context.} The setup uses five negotiators with private score sheets and whole-number walk-away thresholds in a data-centre bargaining scenario.

\textbf{The problem (why this was done).} The problem is whether exact decision support improves frontier-model bargaining without leaking anyone else's private values. 

\textbf{What we did / what changed.} We played the same frozen parameter sets and seeds under each lineup using anthropic:claude-opus-5, with explicit model thinking and public persuasive messages, then paired every contrast on parameter set and seed. 

\textbf{The result.} The all-LLM normalized collective score was 0.873 [0.833, 0.910] (higher is better and a failed negotiation scores zero); replacing one rotating seat with the private rational policy changed it by -0.186 [-0.267, -0.106]. Five rational agents versus one rational plus four LLMs changed it by -0.498 [-0.590, -0.404].

\textbf{One-sentence version.} Across 600 matched episodes, one rational seat changed normalized collective score by -0.186 [-0.267, -0.106] relative to five LLMs.

\section{Experiments and results}
The primary endpoint is normalized collective surplus, with no deal scored as zero. Deal rate is the fraction
of episodes reaching a valid agreement. Each bracket is a 95\% interval from a bootstrap that resamples the
24 parameter sets as clusters, preserving five correlated rollout seeds within a set.

\section{Method and interpretation}
There are 24 independently generated parameter sets. Every LLM turn
uses explicit thinking and the canonical data-centre prompt with private information. The private rational
policy sees only its own sheet and public actions. The omniscient policy sees every sheet and uses the same
exact best-response implementation as the visualizer. Each stored turn is replayed twice to attach both
counterfactual actions; the interactive campaign visualizers plot the actual action, private-rational
counterfactual, and omniscient counterfactual together.

Intervals quantify variation across this frozen parameter-set population, not model or scenario universality.

\section{Relationship to earlier experiments, significance, and next steps}
Earlier project runs established that a computable rational seat can alter both agreement and distribution,
but many used six seats, fixed treatment positions, thinking-disabled API calls, few independent games, or
full information. This campaign directly closes those gaps with five seats, rotating positions, explicit
thinking, 24 parameter-set clusters, and private information. Effects whose clustered interval excludes zero
are resolved for this bank; the continuous difficulty correlation and tag-stratified results test whether any
benefit concentrates in structurally hard games. The most useful next replication is a second frontier API
family or a hosted 32B+ open model on the frozen bank.
